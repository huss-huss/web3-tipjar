# contracts

Solidity contracts for web3-tipjar (Hardhat 3, viem, node:test, OpenZeppelin 5).

```bash
npm ci
npm run compile
npm test            # node:test + viem suite
npm run coverage
npm run node        # local Hardhat node
npm run deploy:local
npm run export-abis # refresh frontend/src/contracts/abis.ts
```

See the [root README](../README.md) for the contract API and
[SECURITY.md](../SECURITY.md) for the security review.
